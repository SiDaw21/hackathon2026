# База данных «Длинный день на маяке» (OpenServer + phpMyAdmin)

## Что внутри архива
- `index.html`, `style.css`, `game.js` — игра.
- `sql/lighthouse_game.sql` — файл базы: игроки, сохранения прогресса, ачивки, рекорды, статистика.
- `api/config.php`, `api/player.php`, `api/sync.php`, `api/load.php`, `api/leaderboard.php` — связь игры с базой.

## Установка
1. Распакуйте архив в папку домена OpenServer, например `domains/lighthouse/`.
2. Откройте phpMyAdmin, вкладка **«Импорт»**, выберите `sql/lighthouse_game.sql` и выполните. База `lighthouse_game` создастся сама.
3. Если у вашего MySQL пароль не пустой — поправьте `$pass` в `api/config.php` (по умолчанию OpenServer: пользователь `root`, пароль пустой).
4. Открывайте игру через домен OpenServer (например `http://lighthouse/`), а не файлом `file://` — иначе PHP не заработает.

## Как это работает
- При вводе ника и старте игры создаётся игрок в таблице `players`; его **ID** показывается в HUD рядом с именем. Один ник = один ID.
- Прогресс автоматически пишется в таблицу `saves` (и дублируется в localStorage как запасной вариант), ачивки — в `player_achievements`, итоги смен — в `leaderboard`.
- В главном меню в разделе «Рекорды» игра подгружает топ-10 из базы; если база недоступна, честно показывает локальные рекорды.
- Посмотреть сохранение вручную: `api/load.php?nickname=ВашНик`.
